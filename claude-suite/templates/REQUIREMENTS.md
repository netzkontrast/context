# Project Requirements

This document tracks all features and boundaries to be built.
Each requirement must be: Specific, User-centric, Atomic, and Independent.

## Categorized Requirements

### Category: [E.g., User Authentication]
- **[REQ-01]**: User can register with email and password, triggering a verification email.
- **[REQ-02]**: User can securely login and stay authenticated via JWT token.
- **[REQ-03]**: User can reset their password via an expiring email link.

### Category: [E.g., Content Management]
- **[REQ-04]**: User can create a new textual post using a markdown editor.
- **[REQ-05]**: User can edit only their own posts.
