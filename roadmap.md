# Roadmap / PROJECT.md

*This file represents the overarching immutable vision statement detailing overarching methodology and stack choices.*

## Core Vision
To construct a highly interconnected, autonomous "Claude Suite" developer toolkit relying entirely on deterministic context engineering, Event-Driven Architecture, and the Model Context Protocol (MCP).

## Architectural Boundaries
- **Stack:** Node.js, Commander (CLI), SQLite (Context Engine).
- **Paradigm:** Hexagonal Architecture (Ports and Adapters).
- **Execution:** Wave Execution Strategy via Directed Acyclic Graphs (DAGs).
- **Security:** Zero-Trust AST Sandboxing (Nyquist Layer).
- **Modularity:** Agent personas are dynamically loaded and not rigidly fixed. They rely on "Progressive Disclosure" to prevent mega-prompt bloat.
